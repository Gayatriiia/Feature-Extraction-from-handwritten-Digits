# Feature-Extraction-from-handwritten-Digits

## Project Description

This project focuses on extracting meaningful features from handwritten digit images and analyzing their effectiveness for classification.

## Objective

To identify and compare different feature extraction techniques for handwritten digit classification.

## Dataset

Handwritten Digits Dataset (Not in MNIST)

## Technologies

- Python
- Jupyter Notebook
- NumPy
- OpenCV
- Scikit-learn
- Matplotlib
